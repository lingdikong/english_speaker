# UI 规范 v2：English Speaker 自有视觉（深色沉浸 · 声波型）

三端（iOS / Android / PC）共用本规范。**视觉基准是 `docs/design/visual-v2.html`**（浏览器打开即可看到全部页面、两套主题、交互演示）。本文档与设计稿冲突时以设计稿为准；设计稿没画到的页面按本文档描述来做。

> 旧版“对标 Apple Music”的规范已废弃。为降低商用风险：**不得**使用 Apple Music 红、SF Symbols 之外的苹果专有素材、流动渐变背景、大封面播放页、“现在就听”等 Apple Music 特有命名与布局。

品牌名：English Speaker。品牌图形：圆角方块内 5 根竖条声波（见设计稿左上角）。

## 1. 设计原则

原文是主角，声波是进度。品牌色只点不铺。两套主题同结构、同令牌，跟随系统切换，也可在设置中固定。

### 1.1 视觉工效十条（必须遵守）

1. 正文对比度 7–14:1，不用纯黑底、纯白字。
2. 夜间用低饱和石墨灰（不是深蓝），白天用柔灰（不是纯白）。
3. 信号青只用于：播放键、当前词、进度（以及选中 Tab / 选中导航项的淡底），合计不到画面 5%。
4. 播放页当前句固定在可视区约 35% 高度，换句时文字平滑上移。
5. 非当前句 55–65% 亮度（令牌 `other`），未转换的句更淡（`pending`）。
6. 原文每行约 35–60 字符，行高 1.5–1.6；当前句 24/38，其它句 19/30（PC 右侧面板 23/37 与 18/29）。
7. 原文字重 700，夜间 650（Android/iOS 无 650 时用 SemiBold 600）。
8. 无常驻动效：不用流动背景；高亮与滚动过渡 200–300ms；跟随系统“减少动态效果”。
9. 专注模式：播放中 5 秒无操作，收起次要控件，只留原文与声波；轻点任意处恢复（设置里可关）。
10. 不只靠颜色：当前词 = 底色胶囊，连读 = 弧线 ‿，弱读 = 小一号，音变 = 点线下划线。

### 2.2 字体（全部 OFL，离线打包进各端，不走网络）

- 标题 / 品牌：**Space Grotesk** 600/700，字距 -0.02em。
- 界面与原文：**Manrope** 500/600/700；中文回退系统字体（PingFang SC / Noto Sans SC / 微软雅黑）。
- IPA 音标：**Noto Sans** 400/500。
- 字号：大标题 32（PC 30）、区块标题 20、列表标题 15/700、次要 13、小标签 12/700 字距 0.08em、Tab 文字 11/700。

### 2.3 形状、尺寸、动效

- 圆角：药丸/圆按钮 999；卡片 18–22；输入框 14；Sheet 顶角 28；封面 = 边长 / 4.5。
- 触控区 ≥ 44（PC 按钮 40）。
- 动效：位置/尺寸用弹簧（CSS `cubic-bezier(.32,.72,0,1)` 0.42s；iOS `.spring(response:0.42, dampingFraction:0.86)`；Compose `spring(dampingRatio=0.86f, stiffness=380f)`）；透明度 0.2s。减少动态效果时直接切换。

### 2.4 玻璃材质

背景模糊 10px + 饱和度 180%，叠 `glass` 底色，`glass-hi` 顶部 1px 内高光，`glass-edge` 1px 内描边，`glass-shadow` 投影。要求**能隐约看见后面的内容**。

- PC：`backdrop-filter: blur(10px) saturate(180%)`。
- iOS：`.ultraThinMaterial` 上再叠 `glass` 色（不要用系统 TabView / Liquid Glass 的默认外观，底部栏是自绘的）。
- Android：用 Haze（`dev.chrisbanes.haze`）或 API 31+ `RenderEffect` 实现背景模糊；更低版本退化为 `glass` 色 alpha 提高到约 0.85。

### 2.5 内容在玻璃下渐隐

玻璃层在最上层，下面的滚动内容用遮罩逐渐淡出，但**不完全消失**（底部仍保留约 20% 不透明度，隐约可见）。分隔线、面板色差也一起淡出。具体渐变停靠点见设计稿 `.fade-under / .fade-m / .fade-m1 / .fade-mp / .fade-panel / .split`。

## 3. 组件

### 3.1 生成封面（声波缩略图，离线确定性，三端一致）

`card` 底 + `line` 1px 内描边，圆角 = 边长/4.5，内部一排竖条声波，颜色 accent 或 violet（列表中按行号奇偶交替；播放中/继续收听用 accent）。

算法（与设计稿 `seedOf / bars` 完全一致，种子用文章标题）：
```
seed = FNV-1a32(title)               // h=2166136261; h^=c; h=imul(h,16777619)>>>0
x = seed || 1
for i in 0..<n:
  x = (x*1103515245 + 12345) mod 2^32
  r = (x >>> 8) / 16777216
  e = sin(π*(i+0.5)/n)
  h_i = round(min + (max-min) * min(1, 0.3r + 0.7r·e + 0.15e))
```
缩略图参数：边长 s，n 根（72→11，56→9，48→7，38→6），min = round(s/10)，max = s − round(s/2.6)，水平内边距 round(s/7)，条间距 2，条圆角 2。

### 3.2 声波进度条

同样用上述算法（种子为文章 id），每根条的颜色：已播放 `accent`，已缓冲 `wave-b`，未合成 `wave-e`；底对齐。拖动/点按 → `seek`。移动端播放页 56 根、高 32、间距 3；PC 播放条 120 根、高 10、间距 2。时间标签：已播 / `-剩余`，时长未定稿时剩余前加“约”。

### 3.3 合成状态 chip（替代旧版下载图标）

| `AudioStatus` | 显示 |
|---|---|
| `NotCached` | ghost chip “未转换”（点按开始转换） |
| `Queued` | accent chip “排队中” |
| `Synthesizing` / `Partial` | accent chip：小进度条 + `ready/total` |
| `Ready` 未钉住 | 不显示 |
| `Ready` 已钉住 | 实心书签（accent）+ “已保存”（accent-text） |
| `Failed` | danger chip “失败 · 重试” |
| 正在播放（PC 列表） | accent chip “正在播放”，整行 accent-soft 底，标题 accent-text |

### 3.4 原文与跟读标注

- 当前句放在 `card` 卡片里（圆角 22，`accent-soft` 1px 内描边 + `elev`），其它句直接排在底色上。
- 当前句内：已读词 `t1`，当前词 `accent-text` + `accent-soft` 胶囊（圆角 9，左右内边距 6），未读词 `t2`。
- 连读 `‿` 用 violet 画在两词之间；弱读词 0.84em、`t3`（已读后 `t2`）、字重 600；闪音/同化/省音：词下 2px violet 点线。
- 当前句下方 chip：“N 处连读”（violet）“N 个弱读”（muted）。
- 非当前句 `other`，未合成句 `pending` 且不可点。
- 标注开关关闭后：去掉 ‿、点线、弱读缩小，只保留逐词高亮。
- 点按句 → `seek_sentence(index)`；点按词 → 点词读音面板（§4.5）。
- 用户手动滚动后暂停自动跟随，3 秒后或点“回到当前句”恢复。

## 4. 移动端（iOS / Android 一致）

### 4.1 导航：4 个 Tab

首页（home）/ 资料库（lib）/ 搜索（search）/ 设置（gear）。图标为 24 网格、1.75 描边的线性图标（选中 2.0），SVG 路径见设计稿 `P` 对象，三端用同一套路径（iOS 用 `Path`/SVG 资源，Android 用 ImageVector）。

### 4.2 底部栏三态（核心交互，必须完整实现）

两个玻璃药丸：**播放条**（有正在播放/最近播放的文章时才出现）和**导航**。高度都是 60，左右边距 16，底部离手势条 26，两个元素间距 10。

| 状态 | 条件 | 布局 |
|---|---|---|
| A 默认 | 列表在顶部 | 两行：播放条 bottom 96、导航 bottom 26，都占满宽度 |
| B 滚动后 | A 下向下滚动超过 24pt | 一行：导航收成左侧 60×60 小球（显示当前 Tab 图标，accent-text）；播放条 left 86 占满剩余 |
| C 点开导航 | B 下点左侧小球 | 一行：导航展开（right 86）；播放条收成右侧 60×60 小球（只剩圆形封面 + 进度环） |

- C 下点右侧小球 → B；任一状态滚回顶部（< 4pt）→ A；**C 下继续滚动保持 C**。
- 位置/宽度弹簧过渡，内部内容 0.2s 淡入淡出。
- 只有一行时，列表渐隐区相应缩短（`.fade-m1`）。
- 没有播放条时：A 只有导航；B 只有左侧小球；点小球直接展开导航（无 C）。
- 播放条内容：46px 圆形封面（`card` 底，内部 5 根 accent 声波）+ 2.5px 进度环（槽 `wave-e`，进度 `accent`，从 12 点顺时针）· 标题（14/700）+ 当前句开头（12，accent-text）· 暂停/播放 · 下一句。Buffering 时播放按钮处显示小转圈。点按播放条主体 → 打开播放页。
- 4 个 Tab 页都适用这套行为（每个 Tab 自己的滚动容器驱动状态）。

### 4.3 首页

大标题“首页”；“继续收听”卡片（surface 面板，72 封面 + 标题 18 + “第 x/y 句 · 剩余 N 分钟” + 48 播放键 + 4px 进度条）；“最近添加”列表（同资料库行）。无内容时显示空状态：品牌图形 + “导入第一篇文章” 按钮。

### 4.4 资料库

见设计稿。大标题“资料库” + 右上 搜索（control 底）/ 导入（accent 底 +）。筛选 chip：全部 N / 转换中 N / 已保存 / 未转换（选中 accent，其余 muted）。“继续收听”卡片。“全部文章”列表行：56 封面 · 标题 15/700 · “时长 · 音色” + 状态 chip · 更多（⋯）。长按或 ⋯：保存（钉住）/ 取消保存、换音色、删除缓存、删除文章。

### 4.5 播放页（原文为中心，无大封面）

- 顶部：收起 ↓ · “第 x / y 句” · 更多 ⋯；下一行 48 封面 + 标题 17 + “音色名 · 美音/英音” + 保存按钮。
- 中间：原文（§3.4），当前句固定在约 35% 高度，在控制面板下渐隐（`.fade-mp`）。
- 底部：玻璃控制面板，bottom 10、左右 10、圆角 38（与屏幕圆角同心），内边距 16/18/20：
  - 声波进度条 + 时间；
  - 第一行：倍速 chip（点按循环 0.75/1.0/1.25/1.5）· 上一句 · 72 播放/暂停 · 下一句 · 单句循环（开启时 accent-text）；
  - 第二行：跟读标注 chip（violet，开关）· 阅读设置 chip · 待播清单。
- 专注模式：顶部两行与面板第二行淡出，原文上移，面板只剩声波 + “专注模式 · 轻点任意处显示控件”。
- 点词读音：底部 Sheet（surface，顶角 28）：词组 34 Space Grotesk（‿ 用 violet）+ IPA 20 violet-text + 发音按钮；类型 chip（如“跨词闪音”）+ “美式发音”；中文说明；“同类”示例卡；按钮“从这里播放”（accent）/“0.75× 慢放这句”。
- 待播清单：Sheet，“正在播放” + 待播列表（拖动排序、左滑删除），当前播完自动播下一篇（客户端维护队列）。

### 4.6 导入

底部 Sheet：关闭 · “导入文章” · 分段（粘贴文本 / 文件 / 剪贴板）· 标题（可选）· 正文 · 音色行 + “导入后立即播放”开关 · “共 N 句 · 预计约 N 秒 · 离线转换，不上传” · 主按钮“开始转换”。确定后立刻出现在资料库并开始合成（边听边转）。

### 4.7 设置 Tab

大标题“设置”，分组卡片（card 底，行高 54，行间 line 分隔）：

1. **外观**：主题分段（跟随系统 / 白天 / 夜间）。
2. **阅读**：字号滑杆（预览当前句，标准 24，范围 20–30）；行距分段（舒适 1.6 / 紧凑 1.4）；非当前句亮度（50/60/70%）；专注模式开关；显示跟读标注开关。阅读设置 Sheet（播放页里打开）与这里是同一组设置，见设计稿“阅读设置”。
3. **朗读**：默认音色（`voices()`）；默认倍速。
4. **本地缓存**：用量条（`cache_stats()`：已用 / 上限，已保存的部分单独标出）；缓存上限（1 / 2 / 5 GB / 不限，`set_cache_limit`）；“清除未保存的缓存”（danger 文字，二次确认，`clear_cache()`）；说明“已保存的文章不会被自动清理”。
5. **关于**：版本、模型（Kokoro-82M v1.0 int8）、“完全离线，文章不会上传”、开源许可（Kokoro Apache-2.0、ONNX Runtime MIT、字体 OFL、misaki 词典 Apache-2.0 等）。

主题与阅读设置保存在客户端（UserDefaults / DataStore / localStorage）。

### 4.8 搜索

顶部搜索框（card 底，圆角 14），按标题与正文过滤（客户端过滤 `list_articles` + `get_article`），结果用资料库行样式，命中的词用 accent-soft 胶囊标出。

## 6. 状态与数据来源

所有数据来自核心层，**UI 不自行推导业务状态**：

| UI | 数据 |
|---|---|
| 文章列表 | `list_articles()`；`LibraryChanged` 后刷新 |
| 合成进度 chip | `ArticleSummary.ready_sentences / total_sentences`；`SynthesisProgress` |
| 播放状态 | `PlayerStateChanged`（含 `Buffering`、`duration_final`） |
| 进度、当前句/词 | `PlayerPosition{position_ms, buffered_ms, sentence, word}`（约 100ms 一次） |
| 原文 | `timeline(id)`：全部句子（`ready`）+ 每词时间 + 跟读标注 `notes` |
| 缓存 | `cache_stats()` / `set_cache_limit` / `clear_cache`；`CacheChanged` |

事件可能来自后台线程，必须切回主线程更新 UI。

## 7. 验收标准（每端）

1. 真实运行（模拟器 / 桌面窗口），连接真实核心库，不是静态假数据。
2. 夜间、白天各一套截图：首页、资料库（含多种合成状态）、底部栏 A / B / C 三态（移动端）、播放页（含逐词高亮 + 跟读标注）、专注模式、点词读音、导入、设置（含缓存）。PC 另截窗口缩放到较窄/较宽时播放条仍居中。
3. 导入一篇文章 → 立即播放（看到 Buffering → Playing）→ 逐词高亮跟随 → 点按某句跳转，全程跑通。
4. 与设计稿并排对比，颜色、尺寸、间距一致；不出现旧版 Apple Music 风格元素（红色强调、大封面、流动背景、“现在就听”）。
