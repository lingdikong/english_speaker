移动端（iOS / Android）

每个关键页面都给出夜间与白天两版。底部导航（首页 / 资料库 / 搜索 / 设置）与迷你播放条为居中的玻璃药丸，列表在其下淡出并隐约可见；播放页控制区保留完整面板（同心圆角的玻璃面板），原文在其下淡出。播放页的当前句固定在屏幕约 35% 高度（视线不移动，文字滚动）；专注模式在 5 秒无操作后收起次要控件；阅读设置提供字号、行距、主题与“非当前句亮度”。

桌面端（Windows / macOS / Linux）

底部为居中的药丸形悬浮玻璃播放条，位于最上层；其下方的列表与原文向下逐渐淡出消失。左侧导航含“设置”（本地缓存等在设置中）。播放条：左侧单句循环 / 上一句 / 播放 / 下一句 / 倍速，中间封面 + 标题 + 声波进度，右侧原文 / 待播 / 跟读标注 / 音量。右侧原文面板行宽约 60 个字符；两套主题同结构。
